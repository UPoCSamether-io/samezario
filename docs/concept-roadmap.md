# サメザリオ (Samezario) 構想設計書 ＆ ロードマップ

**作成日**: 2026-08-16  
**位置づけ**: U☆PoCコンテスト（テーマ①：地域の歴史発信 / 調布市長賞）向け機能拡張 ＆ 本格ゲーム化構想  
**技術方針**: 現行の技術スタック（Vite + Vanilla JS/Canvas2D + Tailwind v4 + Node.js WebSocket 権威サーバ・依存ライブラリゼロ）を完全維持

---

## 1. コンセプトと目的

### 1.1 背景と目的
調布市には映画撮影所、深大寺、郷土博物館、多摩川、水木しげるゆかりの地など豊かな地域資源が存在しますが、若年層や来訪者への認知・回遊促進には課題があります。  
本プロジェクトは、軽量で爽快な .io 系リアルタイムアクションゲームに**「現地写真撮影によるエリア解放」「調布の歴史・名所学習」「SNS拡散」**を組み合わせ、**「遊びながら調布を巡る地域回遊型エンタメ」**を提供します。

### 1.2 コア体験サイクル
```
[1. 街歩き・スポット訪問] ──▶ [2. 現地写真撮影 & 照合] ──▶ [3. エリア解放 & 赤ピン演出]
         ▲                                                               │
         │                                                               ▼
[6. 新サメ獲得 & ラスボス撃破] ◀── [5. マルチ対戦 & 名物獲得] ◀── [4. 歴史解説 & SNSシェア]
```

## 3. 現地写真照合 ＆ 進捗システム

### 3.1 依存ライブラリゼロの写真照合（dHash + ジオフェンス）
屋外写真のブレ（天候・時間帯・アングル）を吸収しつつ、不正を防止する**2段構えの判定**:

```
[ユーザー撮影]
   │ <input type="file" capture="environment"> でOSカメラ直起動
   ▼
[① 位置チェック（厳密）]
   │ navigator.geolocation.getCurrentPosition()
   │ 対象スポットの座標から 150m (または200m) 以内か判定（Haversine距離）
   ▼ 範囲内
[② dHash画像照合（ゆるやか）]
   │ Canvas2D で 9×8 グレースケールに縮小 ──▶ 64bit BigInt ハッシュ生成
   │ 参照ハッシュ群とのハミング距離を計算（しきい値 14〜18）
   ▼ 合格
[③ エリア解放 ＆ 進捗スナップショット更新]
   │ progress.js: clearSpot() / markShared()
   │ localStorage に永続化 ＆ 赤ピンドロップアニメーション
```

- **審査・開発用デモモード**: `?demo=1` クエリまたは設定トグルで、位置や写真照合をスキップして即座に解放演出・ボス戦を実演可能。

### 3.2 解放演出 ＆ 歴史スポットカード
1. **解放演出**: 画面フラッシュ ＋ 未解放マスク消滅 ＋ **赤ピンが上空からドロップ＆2回バウンド**するアニメーション。
2. **スポット詳細カード**: ピンタップで、調布市郷土博物館提供の公式写真・史実解説・豆知識モーダルを表示。
3. **SNSシェアボーナス**:
   - Web Share API（`navigator.share`）を活用し、撮影写真＋「`#サメザリオ #調布のうみ #調布市郷土博物館`」でX等へシェア。
   - シェア実行でボーナスポイント（`+100pt`）を付与（1スポット1回限り）。

## 4. バトル ＆ ゲームプレイの深化

### 4.1 深大寺ラスボスステージ（ボス連戦システム ＆ 専用HPゲージ）
- **出現条件**: 深大寺エリア解放後に突入可能。
- **専用UI**: 画面上部に**ボス専用HPバー（残耐久ゲージ）**を表示。
- **基本バトルルール**:
  - 通常のサメザリオ同様、プレイヤーの頭がボスの胴体に触れると即死の危険。
  - プレイヤーは**ボスの頭部に自分の胴体を当ててカウンターを狙う**。ボスの頭がプレイヤーの胴体に触れるたびにボスのHPが 1 減少。

#### 【第1形態】ラスボス：深大寺のヌシ（メガロドン）
- **HP（被弾許容回数）**: **10回**
- **特徴**:
  - 巨大な体躯と金色のオーラ。
  - 最寄りのプレイヤーを執拗に追跡し、定期的に周囲の餌を吸い込む「トルネード吸引」を使用。
  - プレイヤーの胴体に10回激突してHPが0になると撃破。

#### 【第2形態】裏ボス：真・深大寺のヌシ（覚醒メガロドン）
- **出現条件**: 第1形態撃破直後、画面暗転・激しい水飛沫演出とともに連続出現。
- **HP（被弾許容回数）**: **20回**
- **特殊ギミック（自己再生）**: **30秒ごとにHPが1回復**するリジェネ持ち。
- **特徴**:
  - 紫煙と稲妻を纏い、旋回速度と突進速度が上昇。
  - 時間経過でHPが回復するため、ダッシュやスキルを駆使して手際よく胴体を当て続ける「DPSチェック」的な高難度バトル。
- **撃破報酬**: 
  - 深大寺完全踏破アチーブメント、真のエンディング演出。
  - 限定サメスキン（「覚醒・深大寺サメ」または「黄金のメガロドン」）のアンロック。

### 4.2 調布モチーフのスペシャル餌
通常のプランクトン餌に加え、低確率で調布名物の特殊アイテムが出現：
- **深大寺そば / だるま**: 一時的に体長急成長 ＆ 激突ガードバリア。
- **映画フィルム缶**: 取得すると周囲の敵サメを一定時間スローダウン。
- **多摩川の鮎 / 調布野菜**: スタミナ（ダッシュゲージ）全回復 ＆ 高スコア。

## 5. Web Audio API によるピュア音響（BGM / SE）

外部音声ファイルや外部ライブラリを使わず、ブラウザ標準の **Web Audio API（オシレーター＋ゲインノード）** のみでレトロポップシネマ調のサウンドを完全生成（アセット容量 0 バイト）。

- **SE（効果音）**:
  - 餌捕食音: 短い矩形波のポップ音（ピッチが徐々に上がる連鎖感）
  - ブースト/ダッシュ音: ホワイトノイズのローパスフィルター上昇音
  - スキル発動音: 明るい上昇アルペジオ
  - サメ撃破音: 重低音サイン波＋ノイズのインパクト音
  - エリア解放ファンファーレ: レトロシネマ調の祝勝ジングル
- **BGM**: 8bit/16bit レトロポップ調の軽快なシンセアルペジオ（ON/OFF切り替え可能）。

## 6. UI/UX ＆ モバイル最適化

### 6.1 縦横シームレスな持ち替えUX
- **街歩き・スポット確認・カメラ撮影**: スマートフォン縦持ち片手操作に最適化したレスポンシブUI。
- **ゲームプレイ**: 広い視野と操作性を確保する横画面プレイ（バーチャルジョイスティック / 画面回転ガイダンス）。

### 6.2 オフライン耐性（PWA）
- Service Worker による静的キャッシュで、電波が不安定な屋外でも即起動。
- 通信切断時は `world.goSolo()` により、オフラインBot戦へシームレスに引き継いでゲームが中断しない。
