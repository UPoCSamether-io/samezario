体験

  • 餌を食べて大きくなる。ぶつかったらアウト
  • 「映画のまち」をモチーフにした個性的なサメたち
  • 実際の調布市の形からエリアを起こした。形の違いが遊びの違いになる
  • ブラウザだけで動く。インストール不要、タブレットでもスマホでも
3

仕掛け

ゲームを進めていくと、徐々に歴史が読めるようになる。
▶
▶
  • 常設展示と同じ6区分・全6幕 2,787文字
  • 伏せられた文字を推理する。読むこと自体が謎解きになる
  • 一度読めた文字は二度と隠れない。記録ではなく、伏字の決め方で保証している
  • 100%読めると、新しいサメを獲得できる
4

技術

依存ライブラリは WebSocket 1つ
権威

決めるのはサーバ、先読みはブラウザ

ズレは 25px まで無視し、120px を超えたら位置を合わせ直す

同期

切断しても盤面が途切れない

両側で同じコードを回しているので、その場の海を引き継げる

音

ループの継ぎ目 39.8ms → 1.3ms

Ogg をサンプル単位でループ。効果音は Web Audio API で合成
