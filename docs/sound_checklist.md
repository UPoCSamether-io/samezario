## 🎧 1. BGM（背景音楽）リスト（すべてWebループ対応）

### 【共通UI BGM】
- **タイトル画面 / サメ選択 / ロケ地選択 / 調布図鑑**（1曲に絞り込み統合）
  - **楽曲名案**: 『**青海サーフ**』（作: shimtone）
  - **検索キーワード**: `青海サーフ` / `サーフロック` / `ポップ ロック`
  - **イメージ**: レトロシネマ感とサーフポップの爽やかさがある親しみやすいBGM。

## 🔊 2. 効果音（SE）リスト

効果音ラボ・OtoLogicなどの検索窓で探せるキーフレーズです。

### 【UI・システム操作音】
- `se_ui_decide`: **決定・画面遷移** ➔ [効果音ラボ] システム音 検索: `決定3`
- `se_ui_cancel`: **キャンセル音** ➔ [効果音ラボ] システム音 検索: `キャンセル2`
- `se_ui_hover`: **選択カーソル移動** ➔ [効果音ラボ] ポップ 検索: `ポッ` / `水滴`
- `se_ui_unlock`: **図鑑・アンロック** ➔ [効果音ラボ] 演出 検索: `ファンファーレ` / `達成`
- `se_ui_letterbox`: **帯が開閉する音（シネマ演出）** ➔ [OtoLogic] 検索: `シャッター` / `機械カシャ`

### 【プレイヤー・サメのアクション】
- `se_eat_normal`: **通常のエサ（フィルム等）を食べる** ➔ [効果音ラボ] ポップ 検索: `ぷよっ` / `ぽよん`
- `se_eat_rare`: **クラッパー（カチンコ）を食べる** ➔ [効果音ラボ] 演出 検索: `キラリーン` / `カチンコ`
- `se_dash_start`: **ダッシュブースト開始** ➔ [効果音ラボ] 戦闘 検索: `風切り音` / `ジェット`
- `se_dash_empty`: **息切れ（スタミナ0）** ➔ [効果音ラボ] システム音 検索: `ブブー` / `警告音`
- `se_wake_hit`: **航跡に敵が接触** ➔ [効果音ラボ] 戦闘 検索: `バシッ` / `電撃`

### 【スキル・ロケ効果】
- `se_skill_cinema`: **ライト照射（シネマザメ）** ➔ 撮影フラッシュ音 / レンズ音
- `se_skill_yokai`: **妖怪化・ドロン** ➔ ドロン音 / 妖気音
- `se_skill_tamagawa`: **激流・水流加速** ➔ ザバーン！ / 水流破砕音
- `se_skill_jindaiji`: **蕎麦・回復** ➔ ツルツルッ / ほのぼの音
- `se_skill_airport`: **プロペラ・超加速** ➔ キーン！ / 飛行機エンジン音

### 【戦闘・撃破・ゲームオーバー】
- `se_shark_kill`: **敵サメを撃破** ➔ [効果音ラボ] 戦闘 検索: `ドカン` / `爆破ポップ`
- `se_shark_die`: **プレイヤーサメが死亡** ➔ [効果音ラボ] 戦闘 検索: `ドガーン` / `カチンコ締め`
- `se_rank_up`: **1位到達・順位上昇** ➔ [効果音ラボ] 演出 検索: `レベルアップ`
- `se_warning`: **巨大敵サメ接近** ➔ [効果音ラボ] 演出 検索: `警報` / `心臓音`
