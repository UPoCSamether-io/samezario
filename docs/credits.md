# 音素材クレジット

サメザリオで使っている BGM と効果音の出典です。

配布元・作曲者ともにクレジット表記は**任意**（不要）としていますが、作った人がいて成り立っている音なので、
どの音が誰のものかを追える形で残します。曲を差し替えたら、この表も一緒に直してください。

---

## BGM

すべて [DOVA-SYNDROME](https://dova-s.jp/) からダウンロードしたフリー BGM です。
配信サイトの実データ（曲名・作曲者・再生時間）と、手元のファイルの実尺を突き合わせて特定しています。

| 使用箇所 | 曲名 | 作曲者 | 尺 | 配布ページ |
| --- | --- | --- | --: | --- |
| 共通（タイトル／ロケ地選択／サメ選択／図鑑／史料／遊び方／サウンド） | Dark blue night | 蒲鉾さちこ | 2:45 | https://dova-s.jp/bgm/detail/23442 |
| 調布駅・布田 | Swing Queen | shimtone | 1:26 | https://dova-s.jp/bgm/detail/15715 |
| 深大寺 | 雷鳴の閃き | こーち | 2:27 | https://dova-s.jp/bgm/detail/19651 |
| 調布飛行場 | 彗星に乗って（**Track2**） | マニーラ | 1:21 | https://dova-s.jp/bgm/detail/17291 |
| つつじヶ丘・仙川 | Take Me To The Top | GANO | 1:37 | https://dova-s.jp/bgm/detail/2110 |
| 多摩川 | NAGISA | shimtone | 1:33 | https://dova-s.jp/bgm/detail/13218 |

`彗星に乗って` は同名の別曲（yuhei komatsu 作、https://dova-s.jp/bgm/detail/18156 ）が存在します。
使っているのは**マニーラ作のほうの Track2**です。ファイル名の `_2` はこの Track 番号で、
手元のファイルの実尺 81 秒が配布ページの Track2 と一致することで確定しました
（マニーラ版の Track1 は 105 秒、yuhei komatsu 版は Track1〜3 が 161 / 154 / 162 秒で、
いずれも一致しません）。

`Dark blue night` も Track1（エレピ入り）と Track2（SIDE-B、ギターのみ）があり、使っているのは Track1 です。

### 作曲者からの補足

- **shimtone**（Swing Queen / NAGISA）— 「クレジットは基本的に不要ですが、していただけましたらとても嬉しいです」
- **こーち**（雷鳴の閃き）— 「表記してもしなくても問題ありません。もししていただけたらとても嬉しいです」
- **蒲鉾さちこ / GANO / マニーラ** — DOVA-SYNDROME のライセンスに準拠。追加の条件なし

いずれも DOVA-SYNDROME の利用ライセンスの範囲内で、個別の許諾申請は不要です。

## 効果音

| カチンコ（画面遷移するボタン） | 時代劇演出3（カッ！キハーダ） | [効果音ラボ](https://soundeffect-lab.info/) | https://soundeffect-lab.info/sound/anime/ （演出・アニメ[1]） |

効果音ラボは「フリー、商用利用無料、クレジット表記・リンク不要」を明示しています。

### 素材を使っていない音

以下は外部素材ではなく、**Web Audio API でその場で合成**しています（`src/audio.js`）。
オシレータとノイズの数値がそのまま音色なので、出典はありません。

- 餌食い音（連続で食べると半音ずつ上がる）
- 死亡音（自分・他プレイヤーとも。距離と左右で減衰・定位）
- ダッシュ音（フィルムが回る音。押しているあいだ持続）
- スキル発動音

## ライセンスの要点

### DOVA-SYNDROME

- 商用・非商用を問わず利用可。**クレジット表記は不要**。
- 有償・無償のアプリや WEB サービスでの BGM 利用が明示的に許可されています。
- **音源ファイルそのものの配布・販売は禁止**。「エンドユーザーが容易に音源ファイルにアクセス・複製できる状態」も禁止とされています。
- 作曲者が別途条件を設けている場合はそちらが優先されます（本作で使っている6曲には追加条件なし）。

原文: https://dova-s.jp/help/articles/license/

### 効果音ラボ

- 商用利用無料、報告不要、クレジット表記・リンク不要。

原文: https://soundeffect-lab.info/

## 注意

- **DOVA-SYNDROME は 2026年9月15日に「OpenTracks」へ名称変更**が告知されています。
  上記の `dova-s.jp` の URL は変わる可能性があります。リンク切れを見つけたら、
  配布元名と併せてこの表を更新してください。
- 音源ファイルは `public/audio/` に置いており、静的ファイルとしてブラウザから直接取得できる状態です。
  ブラウザで音を鳴らす以上これは避けられませんが、DOVA-SYNDROME の「容易にアクセス・複製できる状態」の
  禁止条項に触れうる論点なので、配布形態を変えるときは再確認してください。
