## 実装方針

### ACTION! ボタン
- 右カラムの最下段に、カラム幅いっぱいの `.btn.primary`（カチンコ型）。文言「ACTION!」、横に小さく `.kbd-badge` で「ENTER」（タッチでは自動で隠れる）。
- 押せると分かる控えめな動き: 既存の `.claim-pulse`（`style.css` L1376、1.6秒周期）と同じ程度の脈動、または数秒おきに `.clapping`（L313）を付けてカチンコを1回鳴らす（音は出さない）。`prefers-reduced-motion` では止める（L316 / L1381 と同じ扱い）。
- `play()` 中は今どおり `disabled`（L1295）。

### Enter で開始
- `cur === 'shark'` のときの `keydown` で Enter → `play()`。
- **IME 確定の Enter で開始しない**: NAME 欄で日本語入力を確定する Enter は `e.isComposing === true`（古い Safari は `keyCode === 229`）。これを除外しないと、名前を確定した瞬間にゲームが始まる。
- フォーカスが他のボタン（「← ロケ地」等）にあるときは、そのボタンの click に任せる。

### NAME の位置
- 今は右カラムの一番上（L295〜302）。ACTION! の直上へ移す。横画面の「ラベルと入力を1行に寝かせる」（`style.css` の `#s-shark .name-pane label` の flex）と説明文を畳む指定はそのまま使う。
- 説明文「最大8人」は実際の上限 `CAP = 14`（`server/index.mjs` L22）と食い違っている。ついでに「最大14人」に直す（文言のみ）。

### 未解放サメを1枠に
- 伏せ字の方針（`main.js` L56〜60「解放前に名前が読めてしまうと…」、L971〜974「見えるのは『まだ居ないサメが1枠ある』ことだけ」）は守る。まとめた1枠も名前・アイコン・色を出さない。
- 一覧は「解放済みのサメ全部 ＋ 未解放が1体以上あれば『🔒 あと N 種類』の1枠」。この枠は押すと図鑑と同じ解放条件の吹き出し（`unlockCopy` L1171）を出すか、何もしない。選択はできない（`selectShark` L1076 の `isUnlockedShark` ガードはそのまま）。
- **ダイヤル（横画面）の前提が崩れる**: タイルは3面×`SHARKS.length` 枚で、`centerTile` は `list.children[SHARKS.length + i]`、`recenter` は `scrollHeight / DIAL_COPIES` で1面の長さを測っている。1面の枚数が `解放済み数 + (未解放あり ? 1 : 0)` に変わるので、添字は `data-i` で引き直し、`centerTile` は「中央の面（`data-copy="1"`）の中で `data-i === i` の要素」を探す形にする。
- `paintLocks` は「表示のたびに塗り直す」（L986〜990 のコメント）。枚数が変わるので、塗り直しではなく**面ごと作り直す**（`renderSharks` の初回生成を毎回に）。

## 受け入れ条件

- [ ] サメ選択の右下（一覧の下）に幅いっぱいの ACTION! があり、押すとゲームが始まる。右上には開始ボタンが無い。
