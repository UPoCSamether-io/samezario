# #5 [P1] すぐ手が届く目標（小さな順位表・「あと N で X 位」・王冠）

**触るファイル**: `src/game.js` / `src/main.js` / `index.html` / `src/style.css`
**触らない（見た目だけの段階）**: `src/sim.js` / `server/index.mjs`。王冠ボーナスを入れる場合だけ `src/sim.js` / `src/sim.test.mjs`（要判断）。
**前提**: #4 の後（`frame()` の `onHud` と `paintHud` / `#hud` を同じく触るため）。

## 目的

いつも「次の目標（あと少しで1つ上）」が見えていて、1位は王冠で狙われる —— 短い目標の連続で手を止めさせない。

## 実装方針

### 順位表を小さく
- 今は PC で上位5人＋自分、幅最大 320px・16px 文字・行間あり → 1280×720 で右上の4分の1近くを占めている。
- 上位3人＋自分（自分が3位以内なら3行だけ）。幅は `w-[180px] md:w-[200px] xl:w-[230px]`、文字は1段階ずつ下げる。カチンコの帯（`h-4`）は残す（他の板とそろえる）。
- 横画面（`max-height: 500px`）は既にスリム帯（1位と自分、自分が1位なら1位と2位、`style.css` L833〜838）。この挙動は変えない。`board` が3件になっても `.board-lead` / `.board-second` / `.board-me` の付け方（`main.js` L1331〜1339）はそのまま使える。
- タップで展開（`.expanded`、L1407〜1416 と `style.css` L851〜）は上位3＋自分を出すだけになるので、展開する意味が薄い。展開を残すなら展開時だけ上位5を出す（`board` は5件送って、表示側で3件に切る方が楽）。→ **game.js は5件のまま送り、main.js で切る**のを推奨。

### 「あと N で X 位」
- 自分の順位 `rank`（L1125）が 2 以上のとき、ひとつ上（`rank - 1` 位）のサメの質量との差 `N = 上の質量 − 自分の質量 + 1`。
- game.js が `next: { rank: rank - 1, mass: 上の質量 }` を onHud に載せる（全員を質量順に並べた配列は既に `board` を作るときに作っている）。
- 自分の行に小さく「あと 23 で 4位」。1位なら「1位キープ中」等は出さない（王冠で分かる）。横画面のスリム帯では「+23→4位」の短縮形（幅 240px に収める）。

### 王冠
- 1位 = 生きているサメの中で質量最大（ボスは除く。深大寺のヌシは質量 8000〜13000 で常に1位になってしまう）。
- `drawShark` の名前の上に、黄色の王冠（Path2D をモジュールで1回作ってキャッシュ、塗り＋インクの縁）。サイズは画面 px で一定（`/ cam.zoom`）。
- 名前は `cam.zoom > 0.4` でしか出さない（L514）が、王冠は引きの絵でも出す（狙う目標なので）。
- 自分が1位なら自分の頭上に王冠 —— #3b の「あなた」目印（▼、黄色）と同じ位置・同じ色にならないよう、王冠を名前の上、目印をさらに上に積む。

### 王冠ボーナス（要判断。入れるなら別 PR）
- 入れる場合は sim.js の `die()`（L683〜）で「死んだのがその時点の1位なら、ばら撒く餌を増やす」（例: 75% → 100%、1粒の価値 ×1.5）。判定もばら撒きも authority 側の `resolve` 内で閉じるので、サーバとクライアントの同期の問題は増えない。`sim.test.mjs` に §28 を足し、サーバを再デプロイ。
- **まず見た目だけ**を入れる（issue の指示どおり）。

## 受け入れ条件

## リスク

- **sim.js 同期**: 見た目だけなら無し。王冠ボーナスを入れる場合も authority 側で完結する。
- **描画負荷**: 王冠は1体ぶん、キャッシュした Path2D の fill/stroke 1回ずつ。
- **スマホ横**: スリム帯の幅 240px（`style.css` L803）に「+N→X位」を足すと 11px 文字で溢れやすい。数字が4桁になった時を必ず確認。
- **衝突**: `paintHud` と `#hud` は #4（コンボ・キルフィード）と共有、`frame()` の HUD は #3a・#4 と共有 → #3a → #4 → #5 の直列。`drawShark` は #3b（目印の位置）と近い。
