# #8 [P1] 深大寺：湧水（石組みの縁・苔・波紋）

**触るファイル**: `src/game.js` のみ
**触らない**: `src/sim.js`（`springs` / `rearm` / `stock`）/ `src/data.js` / `src/main.js` / `index.html` / `src/style.css` / `server/index.mjs`

## 目的

湧水ゾーンが「破線の円」ではなく、石で囲われた湧き水に見える。「今もらえる／再装填中」の2状態は、湧いている／静か、で一目で分かる。

## 実装方針

### 守ること（既存コメントの判断）
- **2状態は残す**（L749〜751「入っても何も起きない時間が最大 30秒あるので、色で言い分けないと故障に見える」）。判定は今と同じ `player.springT <= 0`（L754）。
- **もらえる間は、ゾーン全体から泡を上げ続ける**（L778〜782「サメが通り抜けた一瞬しか動きがないと、30秒経ったのかどうかが入ってみるまで分からない」）。今の泡（34粒、黄金角、画面 4.5px 下限）は残してよい。
- **自機のまわりに輪を出さない**（`drawEnvFront` L848〜851）。ゾーンの内外は縁と泡が持つ。
- **絵は t だけで決まる**（L783）。石の配置・苔の位置も添字から作る種で決め、乱数を持たない。

### 石組みの縁
- ゾーン半径 `z.r`（460px）の円周上に、大きさの揃わない丸い石を 28〜36 個（隙間を少し空ける）。石は丸めた多角形か `ellipse`。全部を**1本の Path2D**にまとめて、塗り（灰色の石色）1回＋縁（インク）1回。ゾーンごとに1回だけ作ってキャッシュ（ゾーンは動かない）。
- 苔: 石の内側寄りに、緑の小さな塊を Path2D 1本で fill 1回（半透明）。
- 縁の内側の水: 今の放射グラデーション（L761〜765）を残し、もらえる間はミント寄りに明るく、再装填中は灰で暗く（今の色分けを踏襲）。グラデーションはゾーン×2状態で 6本しか無いので、キャッシュして使い回す（今は毎フレーム `createRadialGradient` している）。

### 波紋（もらえる＝湧いている）
- もらえる間だけ、ゾーンの中心付近から 2〜3 本の円が広がって縁で消える（`r = z.r * frac(t * 0.25 + k / 3)`、不透明度は外へ行くほど下げる）。Path2D 1本で stroke 1回。
- 再装填中は波紋も泡も止め、水面を静かに（暗く平ら）。縁の石は両状態とも同じ。
- 自機がゾーンの中に居る（`here`、L758）ときは、縁の石を少し明るく（今の `here` で破線を濃くしていた代わり）。

### 破線
- `setLineDash([30, 22])`（L771）を撤去。issue C の「破線による範囲表示は原則なくす」。

## 受け入れ条件

- [ ] 3つの湧水ゾーンが、石の縁と苔で囲われた水に見える。破線が無い（`drawSprings` に `setLineDash` が残っていない）。
- [ ] ガードをもらえる状態では、泡と波紋が湧き続けている。
- [ ] ゾーンに入ってガードを1個もらうと、全ゾーンが静か（波紋・泡なし、暗い水面）になり、HUD の再装填の秒数（`#hud-spring`）が 0 になると再び湧き始める。
- [ ] 自機がゾーンの中に居ると、縁が少し明るくなる。自機のまわりに輪は出ない（盾を持っていればミントの盾の輪だけ）。
- [ ] 引きの絵でも縁の石が点々ではなく「縁」として読める。
- [ ] 改修前と比べて `drawSprings` の1フレームの時間が増えていない（石と苔はキャッシュした Path2D、グラデーションもキャッシュ）。

## リスク

- **sim.js 同期**: 触らない。`springT` は自機のローカルの値（オンラインでも深大寺は `solo`、`data.js` の `MAPS[].solo`）。
- **描画負荷**: 石 30 個×3 ゾーンを毎フレーム個別に描くと 90 回になる。必ず Path2D にまとめてキャッシュ。今の毎フレームの `createRadialGradient` ×3 もキャッシュに変えるので、改修後のほうが軽くなる見込み。
- **スマホ横**: 特になし（ゾーンは直径 920px で、横画面では画面から大きくはみ出すのは今も同じ）。
- **衝突**: game.js の中で他の issue と同居するが、`drawSprings` は深大寺専用でほかは触らない。#9（全マップの水底）で深大寺の水底（森など）を描くとき、湧水の縁と色がぶつからないよう #8 → #9 の順が望ましい。

## 要判断

1. 石と苔の色味・石の大きさ（寺の庭石風に大きめ／小石を並べた井戸風）。
2. 再装填中の水面を「灰」のまま残すか、「暗い青」にするか（今は灰）。
