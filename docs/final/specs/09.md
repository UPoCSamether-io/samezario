# #9 [P2] 各マップの水底（街区・道・森）

**触るファイル**: `src/game.js` のみ
**触らない**: `src/sim.js` / `src/data.js`（見た目の定義は game.js 側に置く）/ `src/main.js` / `index.html` / `src/style.css` / `server/index.mjs`
**前提**: #6・#7・#8 の後（それぞれのマップの水底の上に何を描くかが決まってから）。

## 目的

全マップ共通の「無地の水＋ドット」をやめ、水の底に沈んだ街・道・森がうっすら見える ——「水没した調布」の世界観が、ギミックの無いマップ（調布駅・布田、つつじヶ丘・仙川）でも伝わる。

## 実装方針

### 守ること（既存コメントの判断）
- **タイル1枚を敷き詰めて、fill 1回**。`dotTile` の L63〜65「60px ごとに fillRect を撒くと、引きの絵ほど重くなる —— 1フレーム 363 → 3458 回。タイル1枚を敷き詰めれば、大きさに関係なく 1回で済む」をそのまま守る。水底の絵がどれだけ細かくても、毎フレームの描画は `fill(outline)` 1回。
- **パターンはワールド座標に敷く**（L888〜889「タイルは world 座標に敷かれるので…カメラと一緒に流れる」）。
- **sim.js の効きは変えない**。水底は飾りで、判定に関係しない。
- **つつじヶ丘・仙川にギミックは足さない**（`data.js` に `gimmick` 定義なし。issue の指示どおり見た目だけ）。

### タイルの作り
- 大きさ 512px 程度（端がつながる＝上下左右で継ぎ目が出ないように、はみ出した図形を反対側にも描く）。
- 不透明度は低く（線・面とも 0.06〜0.14）。水の色 `map.water`（`data.js`）の上で「うっすら底が見える」程度。上に乗る餌・サメ・ギミックの絵より必ず弱く。
- マップ別（案）:
  - `chofu`（調布駅・布田）: 街区。道路の格子（太い通り＋細い路地）と、区画の中の建物の矩形。映画のまちなのでフィルムの縁の穴のような模様を1か所混ぜてもよい。
  - `sengawa`（つつじヶ丘・仙川）: 細い路地が斜めに入り組んだ住宅地（`stage_design_plan.md` §3 ②「入り組んだ地形と狭い通路」）。
  - `jindaiji`（深大寺）: 森。木の樹冠（丸の重なり）と参道。湧水の縁（#8）と色がぶつからないよう緑は暗めに。
  - `airport`（調布飛行場）: 草地と誘導路の線（滑走路本体は #6 が描くので、タイルには入れない）。
  - `tamagawa`（多摩川）: **#7 が川底（石）を描くので、#9 では手を出さない**（今のドットを薄く残すか、何も敷かない）。
- 既存のドット（`rgba(244,239,234,.10)` の 4px 角、60px 間隔）は、水面のきらめきとして全マップで薄く残すか消すか（要判断）。残すならタイルの中に描き込む（fill の回数を増やさない）。

### 引きの絵でのにじみ
- パターンはズームで縮むので、zoom 0.34 ではタイル 512px が画面 174px になり、細い線はにじんで灰色の面になる。線は太め（ワールド 6〜10px）・面は大きめにして、引いても模様として残るようにする。

## 受け入れ条件

- [ ] 調布駅・布田、つつじヶ丘・仙川、深大寺、調布飛行場で、それぞれ違う水底（街区／路地／森／草地と誘導路）がうっすら見える。
- [ ] 水底の模様に継ぎ目（タイルの境目の線）が見えない。
- [ ] 餌・サメ・ギミック（滑走路・湧水）より水底のほうが明らかに弱く、見分けがつく。
- [ ] `draw()` の水の部分は fill 1回のまま（コード上で確認）。
- [ ] 引きの絵（質量 3000 以上）でも fps が改修前と変わらない。
- [ ] 多摩川は #7 の川底のまま（#9 で上書きしていない）。

## リスク

- **sim.js 同期**: 無し。
- **描画負荷**: 方式（タイル1枚・fill 1回）を守れば変わらない。タイルを毎フレーム作り直さない・マップの数だけ作らない（そのマップの分だけ起動時に1枚）。メモリは 512×512×4 = 1MB。
- **スマホ横**: devicePixelRatio 2 でパターンが粗く見える場合は、タイルを 2倍解像度で作って `pattern.setTransform` で 0.5 倍に（対応ブラウザのみ。非対応なら等倍のまま）。
- **衝突**: `draw()` の水の行（L885〜891）は #3b（目印）・#4（パーティクル）・#5（王冠）・#6（影）が触る行とは離れている。マップ別の見た目は #6（飛行場）・#7（多摩川）・#8（深大寺）と重なるので、その3つの後に入れる。

## 要判断

1. マップ別のモチーフ（上の案でよいか。特に調布駅・布田に映画モチーフを混ぜるか）。
2. 今の水面のドットを残すか消すか。
3. 水底の濃さ（「うっすら」の程度）。
