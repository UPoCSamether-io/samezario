# #3b [P0] 開始時にカメラを自機へ寄せ、「あなたはここ」を出す

**触るファイル**: `src/game.js` のみ
**触らない**: `src/sim.js` / `src/main.js` / `index.html` / `src/style.css` / `server/index.mjs`
**前提**: #3a の後（`frame()` を同じく触るため）。

## 目的

始まった瞬間に「自分はどれか・どこに居るか」が分かる。気づいたら壁際だった、を減らす。

## 触るファイルと関数

| ファイル | 場所（行は目安） | 変更 |
| --- | --- | --- |
| `src/game.js` | `const cam = { x: arena.home.x, ... zoom: 1 }` L121 と `player` の生成 L128 | カメラの初期位置を自機に、初期ズームを寄りにする |
| `src/game.js` | `step()` のカメラ L426〜451 | `wantZoom` に「開始からの経過で 1 へ戻る寄り倍率」を掛ける |
| `src/game.js` | `onEvent` の `'warp'` L390 | オンラインで `full` が届いて自機がワープしたら、寄りの演出を最初からやり直す（湧き位置がそこで初めて決まるため） |
| `src/game.js` | `draw()` のサメの後・`drawEnvFront` の前後 L944〜954 | 「あなたはここ」の目印を描く `drawYouMarker(t)` |

## 実装方針

### カメラを寄せる
- 今はカメラが `arena.home`（盤面のどこか）から始まり、`dt * 9` の追従で自機まで**盤面を横切って**飛んでくる（L121, L441）。オンラインでは `full` 到着の `warp` でさらにもう一度飛ぶ。開始直後の絵が落ち着かない原因でもある。
- 初期値を `cam.x = player.x, cam.y = player.y` にし、`introT = INTRO_SEC`（2.5秒）を持つ。`step()` で
  `wantZoom *= 1 + (INTRO_ZOOM - 1) * ease(introT / INTRO_SEC)`（`INTRO_ZOOM = 1.8`、ease は smoothstep）。
  既存の `cam.zoom += (wantZoom - cam.zoom) * min(1, dt * 2.2)` の追従はそのまま使えるので、寄りから自然に引いていく。
- 既存の `fit`（L437、狭い画面を 1280px 相当へ引き上げる）と `clamp(..., 0.34, 1.05)` の後に掛ける。L428〜436 のコメントにある「画面幅によらず見える幅が一定」は寄り倍率が 1 に戻った時点で元どおり。
- `introT` は `world.elapsed` ではなく `step(dt)` の dt で減らす（ポーズ中は止まる。#3a の刻み回しとも整合）。
- `attract`（タイトル背面のデモ）では行わない。

### 「あなたはここ」の目印
- **輪にしない**。`drawEnvFront` L848〜851 のコメント「自機に付く輪は盾の輪（drawShark、ミント・3.9r・明滅）1本だけにする —— 同じ色の輪が2本あると、どちらが『あと1回耐えられる』なのか読めない」に従う。
- 案: 頭上（名前のさらに上）に**黄色の下向き三角 ▼ と「あなた」**の吹き出し。上下にゆっくり弾ませ、無敵（`player.iframe > 0`）の間だけ出して、切れる前の 0.5秒でフェードアウト。サイズは画面 px で一定（`/ cam.zoom`）。
- 色は自機の名前と同じ `YELLOW`（L521 で自機の名前だけ黄色）。ミント（盾）・赤（危険）は使わない。
- 描画は Path2D 1本 + fillText 1回。毎フレーム1個だけなので負荷は無視できる。

## 受け入れ条件

- [ ] ゲーム開始直後、カメラが盤面を横切らずに最初から自機の上にあり、寄った絵から 2.5秒ほどで通常の倍率へ引いていく。
- [ ] オンライン（サーバあり）でも同じ。`full` が届いた瞬間に一度ワープしても、寄りの演出がそこからやり直される。
- [ ] 自機の頭上に黄色の ▼「あなた」が出て、無敵が切れる頃に消える。輪は出ない。盾を持っている間のミントの輪と見間違えない。
- [ ] タイトル背面のデモでは寄りも目印も出ない。
- [ ] 1280×720 と 844×390 の両方で、寄った状態でも目印と自機が HUD（左上の SIZE・右上の順位）に隠れない。
- [ ] ポーズ（Esc）すると寄りの演出も止まり、再開で続きから。

## スクショで確認する画面

- `06-chofu-start-pc/sp`、`10-tamagawa-start-pc/sp`（開始 1.0秒後に撮っている —— 寄った絵と目印が写る）
- `07-chofu-8s` / `11-tamagawa-8s`（8秒後には通常の倍率・目印なし）

## リスク

- **sim.js 同期**: なし（描画とカメラだけ）。
- **描画負荷**: 寄っている間は見える範囲が狭いので、むしろ軽い。
- **スマホ横**: 844×390 は `fit` で既に引いている。寄り 1.8倍だと見える縦が約 200 ワールド px になり、周りの危険が見えない。横画面だけ寄りを 1.4倍に抑えるのを検討（要判断）。
- **衝突**: `step()` のカメラは #4（ヒットストップ・揺れの調整）も触る。`draw()` は #4（パーティクル）・#5（王冠）・#6（飛行機の影）・#9（水底）も触る。挿入位置が違うので並列は可能だが、`draw()` のサメ描画ループ周辺（L944〜963）は同時に触らない。

## 要判断

1. 目印の文言 —— 「あなた」／「YOU」／「あなたはここ」。
2. 寄りの強さと時間（推奨 1.8倍・2.5秒。横画面は 1.4倍）。
3. 目印を無敵の間だけにするか、常に小さく出しておくか（推奨: 無敵の間だけ）。
