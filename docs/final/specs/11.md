ルートに開発用の道具と参考資料が散らばっているのを片付け、初めて見た人が「どれが本体か」迷わないようにする。

## 実装方針

- `git mv` で移す（履歴を残す）。
- **dev サーバからの参照**: Vite の dev サーバはルート以下の HTML をそのまま配るので、移動後は `npm run dev` → `/tools/hash-lab.html` で開ける。2つの HTML の中の import はどちらも `/src/...` の**絶対パス**（`rope-probe.html` L11〜12、`hash-lab.html` も同様）なので、置き場所を変えても壊れない。
- **本番ビルドへの影響**: `vite.config.js` は入口を指定していない（既定の `index.html` だけがビルドされる）ので、移動前も後も dist には入らない。変わらない。
- 文言の更新: 「`npm run dev` → `/hash-lab.html`」を `/tools/hash-lab.html` に（README・各コメント）。
- `README.md` の構成の表に `tools/`（開発用の道具）と `docs/design-reference/`（デザインの参考）の行を足す。
