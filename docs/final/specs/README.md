### 同じファイルを触る組み合わせ

- **`src/main.js` / `index.html` / `src/style.css`**: 01・02a・02b（画面の導線）と 04・05（HUD）。導線系はタイトル・ロケ地・サメ・リザルトで、HUD 系は `#s-game` と `paintHud`。**場所は離れている**が、`style.css` の `@media (max-height: 500px)` のブロックが巨大で両方が触るので、同時に走らせると merge が面倒。
- **`src/game.js`**: 03a・03b・04・05・06・07・08・09。
  - 関数ごとに分かれるもの（並列可）: 06 `drawGust`、07 `drawCurrent`、08 `drawSprings`。
  - **同じ関数を触るもの（直列）**: `frame()` = 03a・04・05 ／ `step()` のカメラ = 03b・04（揺れ）／ `draw()` = 03b（目印）・04（粒）・05（王冠は `drawShark`）・06（影の呼び出し1行）・09（水の fill）。
- **`src/sim.js`**: 03a だけ（05 の王冠ボーナスを入れると 05 も）。
- **`server/index.mjs`**: 10 だけ。
- **`README.md`**: 10・11（別の節）。

## 並列実行順の提案

```
第1波（並列）   01   03a   06   08   10   11
                 │     │
第2波（並列）   02a   03b   07
                 │     │
第3波（並列）   02b   04
                       │
第4波            05    09
```

| 波 | 並列に走らせるもの | 理由 |
| --- | --- | --- |
| 1 | **01**, **03a**, **06**, **08**, **10**, **11** | ファイルが重ならない組み合わせ。01（main/index/style）、03a（sim + `frame()`）、06（`drawGust`）、08（`drawSprings`）、10（server）、11（移動）。03a と 06/08 は game.js を共有するが関数が別。06 が `draw()` に足す1行だけ merge 時に注意。 |
| 2 | **02a**（01 の後）, **03b**（03a の後）, **07** | 02a は 01 と画面の3ファイルを共有。03b は 03a と `frame()`/カメラを共有。07 は `drawCurrent` だけ —— 03a の調査結果（多摩川の描画が重い）を受けて fps を測る必要があるので 03a の後に置いたが、ファイル上は第1波でも可。 |
| 3 | **02b**（02a の後）, **04**（03b の後） | 02b は 02a の規則（見出し・ボタンのクラス）を使う。04 は `frame()`・`step()`・`draw()` を 03a/03b と共有。02b と 04 は main.js/index.html/style.css を共有するが、導線（サメ選択）と HUD で場所が離れている —— 並列可・merge 時に `style.css` の横画面ブロックだけ注意。 |
| 4 | **05**（04 の後）, **09**（06・07・08 の後） | 05 は 04 と `paintHud`・`#hud`・`frame()` の HUD を共有。09 は各マップの水底の上に何が乗るか（06/07/08）が決まってから。05 と 09 は game.js の別の場所（`drawShark`/HUD と、水の fill）なので並列可。 |

**デプロイ**: sim.js を変えるのは 03a だけ（05 のボーナスを入れなければ）。サーバの再デプロイは 03a と 10 を同じ便にまとめると1回で済む。

**#0（shots.mjs）との約束**: `#map-next`・`#start-btn`・`#s-title [data-go="map"]`・`#map-areas path`・`window.__sz.player/arena` を shots が使っている。02a/02b はこの id を引き継ぐこと。03a の後は湧き位置が変わるので、Before/After の比較はシード固定でも盤面が違ってよい。

## 要判断の一覧

| 仕様 | 要判断 |
| --- | --- |
| 01 | 「すぐ遊ぶ」の置き方（分割ボタン推奨）／「1秒以内」をキーを押してから測るか、死亡後の 900ms も削るか |
| 02a | 右上「サメ選択 →」を消すか小リンクで残すか／見出しの新しい見た目／Enter でも次へ進めるか |
| 02b | ACTION! の動き（脈動・カチンコ）／「あと N 種類」の枠を押したときの反応 |
| 03a | 壁から離す距離 `SPAWN_CLEAR`（推奨 450px）／多摩川以外でもギミックを避けて湧かせるか／無敵 3秒は据え置きでよいか |
| 03b | 目印の文言（あなた／YOU）／寄りの強さと時間（横画面は弱めに）／目印を無敵の間だけにするか |
| 04 | 他人同士のキルもフィードに出すか／「自分が倒した」を名前一致で判定するか sim.js に倒した側の nid を載せるか／コンボを何連から出すか |
| 05 | **王冠ボーナスの有無**（推奨: 見た目だけ）／「あと N で X 位」の言い回し／展開時に上位5を出すか |
| 06 | **滑走路番号**（17/35 と理解しているが要確認）／影の機種と大きさ／自機の黄色い矢印を残すか／影をサメの上に描くか |
| 07 | 3帯の水色／河川敷を浅瀬（水）にするか砂利のままか／京王線の鉄橋を入れるか |
| 08 | 石と苔の色味・大きさ／再装填中の水面の色 |
| 09 | マップ別のモチーフ／水面のドットを残すか／水底の濃さ |
| 10 | 総部屋数の既定（推奨 8）／**IP 上限（会場は全員同じ IP になるので推奨: 無効）**／混雑時に「ソロ」と知らせるか／負荷測定の結果の置き場所 |
| 11 | 移動先の名前／stitch の資料を残すか |
