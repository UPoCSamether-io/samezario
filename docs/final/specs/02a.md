**触るファイル**: `index.html` / `src/main.js` / `src/style.css`
**触らない**: `src/game.js` / `src/sim.js` / `server/index.mjs`

#2 は1回で終わらないので分ける。**2a = ロケ地選択と全画面の規則（見出し・戻る）**、**2b = サメ選択**。2a → 2b の順に直列。

## 目的

ロケ地を選んだ人が、迷わず「このロケ地で撮影する →」を押せるようにする。未解放なら同じ場所が「現地で写真を撮って解放」に変わり、袋小路にならない。

## 実装方針

### 主ボタン（ロケ地選択）
- `#map-info` は `flex flex-col` で、`#map-info-body` が `flex-1 overflow-auto`。主ボタンを body の**後ろの兄弟**に置けば、本文がスクロールしても常に見える。
- ラベル
  - 解放済み: 「このロケ地で撮影する →」
  - 未解放: 「現地で写真を撮って解放」（カメラアイコン）。押すと `openUnlock(m)`。今の `disabled` ＋「まだ遊べません」（L576, L581）は廃止。L577〜580 のコメント「押せない理由をボタン自身に出す。…袋小路に見える」の意図は、押せば解放フローへ進むことで満たす。
- 見た目は `.btn.primary`（黄色・塗り・カチンコ）。幅いっぱい・文字は今の `text-sm` より大きく（`text-lg` 程度）。
- `#map-next-label` の `white-space: nowrap`（`style.css` L929〜931「折り返すとボタンが伸びてツールバーごと地図を押し下げる」）は、ボタンがツールバーから出ても**横画面でパネル幅が 170px 級まで痩せる**ので維持する。文言が収まらないなら横画面だけ短縮形（「撮影する →」）にする。

### ダブルクリック／ダブルタップ
- `dblclick` は iOS Safari で当てにならないので、`pointerup` の時刻と対象を覚えて **350ms 以内に同じエリア**なら次へ、を自前で判定する。
- 未解放エリアのダブルタップでは何もしない（解放フローを勝手に開かない）。
- `p.onfocus` も `selectMap` を呼んでいるので、キーボードでは Enter キーで次へ進めるようにしてもよい（任意）。

### 全画面のルール（2a で決めて、2b でも使う）
- **進む** = 大きい・塗り（`.btn.primary`）・右下（パネルや一覧の下＝視線の終点）。
- **戻る** = 小さい・白か枠のみ（今の `.btn` の白で可）・左上。文言は「← 戻る」程度に短く。
- **見出し**（「ロケ地を選ぶ」「サメを選ぶ」「サメ図鑑」）は**黄色の箱 `bg-yellow ink-3 hard` をやめる**。ボタンと見分けるため、枠・影なしの文字だけ（例: 白文字＋インクの縁取り、または下線1本）。クラスを1つ作って3画面で共有する（`.screen-title` など）。
- 右上の `#map-next` を消すと、ツールバーの `grid-cols-[1fr_auto_1fr]`（L181 のコメント「見出しを真ん中の列へ」）が左右非対称になる。右の列は空のまま残すか、小さい文字リンク「サメ選択へ →」を置く（要判断）。

## 受け入れ条件

- [ ] 右パネルの本文をスクロールしても、主ボタンは動かず見えている。

## リスク

- **sim.js 同期 / 描画負荷**: なし。
- **スマホ横**: `#map-cols` は横画面で `1fr min(46vw, 400px)`（`style.css` L1059 付近）。パネル本文は実測 197px しか映らない（`main.js` L582 のコメント）ので、主ボタンでさらに約 56px 減る。史実（HISTORY）が折り返しの下に沈まないか、ボタンの高さを横画面だけ詰める。
- **ダブルタップの誤爆**: 地図のピンチ／スクロールは無いので低い。ただし iOS のダブルタップズーム（`touch-action`）が残っていれば `touch-action: manipulation` を `.map-area` に付ける。
- **shots.mjs**: `#map-next` の id を変えると #0 の撮影スクリプトが壊れる。id は引き継ぐこと。
- **衝突**: #1・#2b と `index.html` / `main.js` / `style.css` を共有。#1 → #2a → #2b の直列。
