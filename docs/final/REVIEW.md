## 2. 人間に確認してほしいこと（重要な順）

1. **スマホ実機での重さ（#08 深大寺・#07 多摩川）**。PC では問題なしとして取り込み済み。GPU なしの擬似環境での #08 による低下は N3 で 2% 前後まで縮めた。重ければ N3 → #08 の順に外す：`git revert -m 1 c5b59e7` のあと `git revert -m 1 5935366`。
2. **本番反映は必ずサーバも同じ版で**。#03a で `src/sim.js` を変えたので、フロント（Cloudflare Pages）とサーバ（EC2）の版がずれるとワープや当たり判定のずれが出る。master への push で deploy-ec2 が両方を出す作りなので、master に入れれば揃う。
3. **オンライン対戦**はローカルのサーバでは OK（N1）。本番サーバでの確認は master 反映後に。会場で同名（既定名 PLAYER）が多いと、同名の別人の撃破を自分の撃破と数える誤判定がまれにあり得る（`src/game.js` の killedByMe）。
   - `final-polish` の Pages プレビューは本番サーバ（旧 sim.js）につながるので、プレビューでの対戦はずれる。プレビューはソロで見ること。
4. **飛行場の滑走路の番号と向き（17/35）** が実際と合っているか。
5. **多摩川の鉄橋の位置**：エリア中央に仮置き。
6. **WS_MAX_ROOMS=8（約112人）** で発表会場の人数に足りるか。
7. スマホの開始時の寄り（1.4 倍）が見やすいか。
8. デモでは質量 3000 以上の引きの絵で飛行場を見せると、影が飛行機に見える。
9. 調布の水底のフィルム帯の模様は「気づく人はほぼいない」（害はない）。残すかどうか。

## 5. 手元での確認方法

